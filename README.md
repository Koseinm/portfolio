# Sein Min Portfolio — GitHub Pages

Static HTML portfolio website. Default page language is Myanmar.

## GitHub Pages တင်နည်း

1. Repository အသစ်တစ်ခု ဖန်တီးပါ။
2. ဒီ folder ထဲက file အားလုံးကို repository root သို့ upload/push လုပ်ပါ။
3. GitHub repository ရဲ့ **Settings → Pages** ကိုဖွင့်ပါ။
4. **Deploy from a branch** ကိုရွေးပြီး `main` branch နှင့် `/ (root)` ကိုရွေးပါ။
5. Save လုပ်ပြီး GitHub Pages URL ပြလာသည်အထိ စောင့်ပါ။
